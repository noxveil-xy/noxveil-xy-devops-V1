# Noxveil-Xy V1

> Персональный сайт-портфолио, посвящённый системному администрированию, инфраструктуре, автоматизации и DevOps-практикам. Информационная безопасность — дополнительное направление, которое помогает выстраивать и поддерживать надёжные системы.

---

## О проекте

**Noxveil-Xy** — персональный сайт-визитка и техническое портфолио. Он представляет мой профессиональный профиль, технические навыки, опыт работы и практические проекты.

Главная цель проекта — показать практический подход к администрированию Linux- и Windows-систем, поддержке серверной и сетевой инфраструктуры, автоматизации рутинных задач и изучению DevOps-инструментов.

### Основные направления

- Системное администрирование Linux и Windows;
- Серверная инфраструктура и виртуализация;
- Windows Server и Active Directory;
- Сетевые технологии и диагностика;
- DevOps-практики и автоматизация;
- Python и Bash для решения инфраструктурных задач;
- Мониторинг, журналирование и обслуживание систем;
- Информационная безопасность как дополнительное направление: hardening, анализ трафика и обнаружение подозрительной активности.

## FS-BOX

**FS-BOX** — приложение для передачи файлов между устройствами и виртуальными машинами внутри локальной сети.

Проект появился как практическое решение задачи передачи файлов между виртуальными машинами без использования облачных хранилищ. В процессе разработки изучаются сетевое взаимодействие и организация клиент-серверного приложения.

Основные технологии:

- Python;
- TCP sockets;
- Client / Server architecture;
- Linux.

Практические темы:

- TCP-соединения;
- Работа с сокетами;
- Клиент-серверная архитектура;
- Обработка подключений;
- Передача данных;
- Работа с сетевыми адресами и портами.

## Network Scan Detector

Инструмент для обнаружения признаков сетевого сканирования и формирования событий для последующего анализа.

Проект помогает изучать сетевой мониторинг, работу с журналами и запуск фоновых служб в Linux.

Планируемые или изучаемые компоненты:

- Захват сетевого трафика;
- Обнаружение признаков сканирования;
- Журналирование событий;
- Анализ логов;
- Ротация логов;
- Фоновый запуск;
- Управление запуском через `systemd`.

## ARP Monitor

Инструмент для наблюдения за ARP-активностью в локальной сети и обнаружения необычных изменений соответствий IP- и MAC-адресов.

Проект дополняет практику работы с сетями и мониторингом, а также позволяет изучать базовые механизмы защиты локальной инфраструктуры.

Изучаемые темы:

- ARP;
- Соответствия IP / MAC;
- Мониторинг изменений;
- Обнаружение аномалий;
- Диагностика локальной сети;
- Базовые меры защиты сети.

# Infrastructure Operations Terminal

В нижней части сайта может располагаться интерактивный терминал, имитирующий рабочую среду системного администратора.

В терминале отображаются примеры команд, системные события, состояние служб и условные показатели инфраструктуры:

- Команды Linux;
- Состояние системных служб;
- Сетевые параметры;
- События и предупреждения;
- Количество условных событий;
- Uptime.

Примеры команд для визуального отображения:

```text
ip addr show
ip route
ip neigh show
ss -tulpn
systemctl status nginx
systemctl --failed
journalctl -p warning
df -h
free -h
top
```

При необходимости в терминале могут встречаться и команды, связанные с сетевой диагностикой и безопасностью, но основное назначение компонента — показать инфраструктурные задачи.

> Терминал является визуальной симуляцией. Команды не выполняются на компьютере посетителя и не взаимодействуют с его системой.

# Подход к разработке

Проект разрабатывается поэтапно:

```text
Архитектура
     ↓
Структура
     ↓
Визуальный стиль
     ↓
Responsive Design
     ↓
Интерактивные элементы
     ↓
Анимации
     ↓
Оптимизация
     ↓
Финальное портфолио
```

Каждая крупная часть сайта создаётся и дорабатывается отдельно. Такой подход позволяет контролировать структуру, внешний вид и поведение каждого компонента.
